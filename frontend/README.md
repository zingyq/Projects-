# Frontend
## Przeznaczenie
Frontend odpowiada za interfejs, funkcjonalność i wygląd, które będę widzieć na ekranie 
## Planowane widoki
Lista zadań — na stronie głównej wyświetlane będą wszystkie zadania, które należy wykonacs
Formularz dodawania zadania — użytkownicy będą modgli wprowadzić nowe zadanie i dodać je do listy
Formularz edycji zadania — w razie potrzeby użytkownicy będą mogli zmienić opis, status lub tytuł zadania
## Technologie
- HTML,
- CSS,
- JavaScript.
## Proponowana struktura
index.html
style.css
app.js
