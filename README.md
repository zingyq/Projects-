# Task Manager
## Opis projektu
Aplikacja do śledzenia zadań, która pomaga uporządkować codzienne sprawy. 
## Cel projektu
Mam nadzieję, że nauczę się korzystać z narzędzi GitHub/Git. Bardzo interesujące jest też przyjrzenie się, jak pracują już programiści full stack. 
## Funkcjonalności
- dodawanie zadań,
- edycja zadań,
- zmiana statusu,
- wyszukiwanie i filtrowanie.
## Technologie
- frontend: html/css/js
- backend: idk
- baza danych: PostgreSQL
## Struktura projektu
```text 
frontend/ 
backend/ 
database/ 
docs/ tests/ 
```
