# Backend
## Przeznaczenie
Nie pracowałem zbyt intensywnie z backendem, ale z tego, co rozumiem, odpowiada on za bazy danych, z których pierwotnie pochodzą informacje 
## Komunikacja
Backend udostępnia API i komunikuje się z bazą PostgreSQL.
## Planowane endpointy
- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/{id}
- DELETE /api/tasks/{id}
